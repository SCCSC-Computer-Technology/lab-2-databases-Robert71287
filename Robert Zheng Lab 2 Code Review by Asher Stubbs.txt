Robert Zheng Lab 2 Code Review
By Asher Stubbs
The GUI for this lab is self-explanatory and usable, though I would have liked to see the buttons laid out/grouped better with possibly group boxes or labels for them. It is also missing an exit and clear/reset button, so once the data table is sorted or altered there is no way to get back to default view. The form itself is missing a window title, and the buttons have inconsistent design names; it could cause issues if labels were added with the same names. The code is missing comments, although it is basically just query calls for each button click, so not much explanation is needed. Exception handling is missing so crashes are possible, either by record adding/editing or by null returns on the query calls. Overall the lab functions fine, but in my opinion needs some further refining to be user-proof.
